# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A technical book, *Observability with Prometheus and Grafana: A Hands-On Introduction*, built
to an EPUB from Markdown, plus its companion lab (`lab/`, called "obslab" in the text). The
lab is a Docker Compose stack around **Snip**, a Go URL shortener, and it grows one increment
per chapter. **Read `STATUS.md` first.** It records what is done, what is unverified and what
work is outstanding, and it is meant to be kept current across sessions.

## Build commands

Run Python through the **3.10 interpreter explicitly**. The Python first on PATH (3.14) lacks
`markdown`, `ebooklib`, `pygments`, `bs4`, `lxml` and `Pillow`. From Windows the interpreter is
`C:/Users/fatih/AppData/Local/Programs/Python/Python310/python.exe`; under WSL it is
`/mnt/c/Users/fatih/AppData/Local/Programs/Python/Python310/python.exe`.

```bash
# Rebuild the EPUB (writes Observability-with-Prometheus-and-Grafana.epub at the root)
"$PY" build/make_manifest.py && "$PY" build/build_epub.py

# Rebuild the lab's git history: 29 commits, tags ch01..ch29. Idempotent; re-inits lab/.git
"$PY" build/chapter_map.py && "$PY" build/cut_tags.py      # --dry-run available

# Materialize the lab as it stands at the end of chapter N
"$PY" build/assemble.py 7 <outdir>        # or: assemble.py 7 --list

# Normalize exercise blocks (run from manuscript/; idempotent; re-run after any chapter pass)
"$PY" ../build/normalize_exercises.py [--write] [--skip 12,13]
```

Go is not installed on the host. Compile checks run in a `golang:1.25-alpine` container; see
`build/fix_history.js` for the invocation.

Lab commands (GNU make, run inside `lab/`): `make check` (static validation via promtool and
`docker compose config`, which must pass before anything starts), `make up`, `make ps`,
`make verify` (the current chapter's assertions; per chapter, `scripts/verify-chNN.sh`),
`make test-rules`, `make reset`. `make help` lists the rest. promtool runs inside the
Prometheus image with an overridden entrypoint.

Chapter writing and verification runs as a Workflow tool script, `build/write_chapters.js`,
with args `{"chapters": [N], "stage": "full"}` (draft, then two independent verifiers for
technical accuracy and teaching, then repair) or `"stage": "draft"`. Its hard-coded `SCRATCH`
and `TODAY` constants may need updating.

## Architecture

**Manuscript to EPUB.** `manuscript/*.md` holds 29 chapters (`chNN-*.md`), front matter
(`00-front-matter.md`) and appendices A–I (`app-*.md`). `make_manifest.py` generates
`manuscript/manifest.json`, which defines the order, the nine Parts with their chapter ranges
(hard-coded in `PARTS`) and the metadata. `build_epub.py` renders the manifest with
`build/styles.css` and `build/cover.png`. Custom `!!! <class>` admonitions map to CSS classes,
so only the classes listed in the style guide render correctly. Files starting with `_` and
`00-OUTLINE` are planning material, not book content. Per-chapter briefs are in
`manuscript/_specs/chNN.md`.

**The lab has two representations, kept in sync by the build scripts:**
- `lab/` working tree: the final (ch29) state, live files.
- `lab/.git`: a **separate, nested git repo**, the reader-facing history, generated by
  `cut_tags.py`. Each tag `chNN` is a full, buildable snapshot of the lab at that chapter. The
  outer repo has no commits.
- `build/chapter_map.json` (derived by `chapter_map.py` from `lab/LAB-SPEC.md` §4 tree markers
  `(chNN)` and the §8 growth plan) says in which chapter each file first appears.
- `lab/.history/chNN/<path>` holds earlier versions of the roughly 18 files that evolve across
  chapters. It is git-excluded scratch. `assemble.py` picks the newest version ≤ N, falling back
  to the live file.

To change what a reader sees at a given chapter, edit the live file and/or the `.history`
versions, then regenerate the tags. Don't hand-edit `lab/.git`.

## Sources of truth, in authority order

When figures, names or behavior conflict, the higher source wins:

1. `lab/MEASURED.md`: measured from the running stack. It outranks everything for any figure.
2. `lab/VERIFY-STATUS.md`: which verify scripts actually pass.
3. `lab/` source, then `lab/SPEC-DELTAS.md` (runtime findings), then `lab/LAB-SPEC.md` (service
   names, ports, metric names, labels, pinned image tags; the main line is Go).
4. `manuscript/_specs/_POLICY.md`, `_DEPENDENCY-GRAPH.md`, `manuscript/_STYLE-GUIDE.md`.
5. `research/*.md` (`00-FACT-SHEET.md` first). **`research/_CONFLICTS.md` is a quarantine list.
   Nothing on it may be printed as fact.**

Never invent a metric name, flag, version, config key or port. If the lab doesn't expose it,
it doesn't exist in the book. Pinned versions are Prometheus 3.13.1 and Grafana 13.1.1.

## Manuscript rules that are easy to violate

`manuscript/_STYLE-GUIDE.md` is binding. Read it before editing prose. The rules that
verifiers most often catch:

- Exactly one `#` heading per chapter: `# Chapter N — Title` (em dash). Sentence-case `##` headings.
- Fixed skeleton: hook, `!!! objectives`, sections, `## Common mistakes`, `## Summary`,
  `## Exercises`.
- Exercises: one `!!! exercise` block with 3–6 items, each `**N. Title (warm-up|core|stretch).**`.
  Solutions go only in Appendix I. Exercises must work against the lab at the end of *that*
  chapter.
- Allowed admonition classes only: `note info tip hint warning pitfall jargon exercise objectives
  iou selfcheck trap sidebar ladder grafana12`. Each chapter needs at least one `selfcheck` with
  a concrete expected output. Every `iou` names the chapter that repays it.
- Code fences must carry a language tag and stay **≤76 chars per line**. ASCII diagrams stay
  ≤72 wide. Tables have at most 4 columns. No raw HTML, images, Mermaid or LaTeX.
- American English, second person, present tense. No "simply/just/obviously". No "this book".
  No page references and no "above/below" as pointers.
- Faults are triggered with reversible `SNIP_*` env-var switches, never by having the reader
  break their own files. Grafana instructions describe intent, not clicks.
- Lab paths are written as `lab/prometheus/prometheus.yml`, and lab steps end with a concrete
  verification.
